# 渝新欧国际铁路联运货物出口虚拟仿真实验 · 专家评审页面

西南政法大学该项目的公开、只读评审页面。此仓库单独保存评审前端及已公开的教学导览资料；不包含教学平台后台、真实账号、学生个人记录、服务器配置或 AI 服务密钥。

## 页面内容

- 项目总览、系统全景、申报书导读和两支项目视频入口
- 九章数字教材的只读阅读页
- 26 步实验的任务、教学设计与评价说明
- 双 AI 教学设计、脱敏教学应用汇总、申报要求对照和治理说明

账号管理、实时网速与排队依赖正式系统，本仓库中的对应页面会引导到正式系统。在线 AI 评审问答依赖服务端，本静态版本只保留双 AI 教学设计介绍。

## 本地运行

需要 Node.js 20 及以上版本。

```bash
npm ci
npm run dev
```

打开 `http://localhost:3000/expert-review`。运行 `npm run build` 后，静态站点在 `out/` 目录，可交给静态网站服务器托管。提交本仓库不会自动改变现有项目网站。

## 接入项目视频

编辑 [`content/review-v2/expert-videos.json`](content/review-v2/expert-videos.json) 中两个对象的 `url`，分别填入项目简介和教学引导的长期有效 HTTPS 视频地址。页面会在本页使用浏览器原生播放器。当前两个地址留空，页面显示待接入状态；MP4 成片不在本仓库中。
